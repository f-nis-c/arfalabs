Page replacement

FIFO, LRU and Optimal run together on the same input.

Manual

Type page numbers with spaces between them. Choose how many frames memory has. Press Run.

Each grid shows time moving left to right. Frame 1 is the bottom row. A dash is an empty frame. Under each column, f means the page was not in memory (a fault) and h means it was (a hit). The totals use the same letters.

FIFO removes the page that has been in memory longest. LRU removes the page unused for the longest time. Optimal removes the page whose next use is furthest away, so it needs the whole string in advance and serves as the lower bound.

Python version: pr.py (run python3 pr.py). Text manual: MANUAL.txt.
